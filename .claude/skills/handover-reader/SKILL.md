# 인수인계 읽기 + 인박스 작업 보고 스킬

## 실행 조건

사용자가 다음 중 하나를 말하면 이 스킬을 실행한다:
- "인박스에 넣어줘"
- "인박스에 적어줘"
- "작업 보고 작성해줘"
- "오늘 작업 보고해줘"
- "인수인계서 적어줘"
- "01_인박스에 저장해줘"

## 실행 절차

### 1. 인수인계 문서 읽기

다음 순서로 문서를 읽는다:

1. `99_AI 인수인계/00.시작하기.md`
2. `99_AI 인수인계/01.AI운영규칙.md`
3. `99_AI 인수인계/03.현재 상태.md`
4. `99_AI 인수인계/20.스킬_작업보고_인박스저장.md`

> 02, 04 문서는 필요시 참고. 00, 01, 03을 우선 읽고 규칙을 파악한 뒤 진행한다.

### 2. Vault 구조 파악

`00_홈`, `01_인박스`, `02_프로젝트`, `03_지식`, `04_아이디어`, `05_자료` 폴더의 상위 문서를 읽어 vault의 현재 상태를 파악한다.

### 3. 현재 세션 작업 추출

이번 세션에서 수행한 작업을 추출한다:
- 파일 생성/수정/삭제
- 빌드, 배포, 커밋/푸시
- 해결한 문제와 그 방법
- 기술적 의사결정과 이유

### 4. 인박스 저장

아래 규칙에 따라 `01_인박스`에 작업 보고서를 저장한다.
